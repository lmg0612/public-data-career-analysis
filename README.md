# 자기주도적 직무탐색 경험이 전공일치도와 직업만족도에 미치는 영향

> 제7회 교육 공공데이터 분석·활용대회 (데이터 분석 부문) · 팀 "세상은 차갑다" · 2025.04~05

## 문제의식
우리나라 대졸자의 약 58%가 전공과 무관한 일을 하고 있습니다(OECD 최하위권). 현장실습·인턴·진로 과목 같은 **자기주도적 직무탐색 경험**이 전공 일치도를 높이고, 그것이 직업 만족도와 안정성 인식으로 이어지는지 공공데이터로 검증했습니다.

## 데이터
- 한국직업능력연구원 **KEEPII 7차**(2023) — 1999년생 청년 패널의 교육·고용 정보
- 한국고용정보원 **재직자 성격·지식 조사**(2023) — 향후 5년 기술적 대체 가능성 인식

## 분석
| 단계 | 질문 | 기법 | 결과 |
|---|---|---|---|
| 1 | 현장실습·인턴, 진로 과목 수강 → 전공 일치도 | Mann-Whitney U | 유의(p < .05) |
| 2 | 전공 일치도 → 발전 가능성·직장 안정성 인식 | 순서형 로지스틱 회귀 | 유의(p < .001) |
| 3 | 발전 가능성·안정성 → 기술적 대체 가능성 인식 | 다항 로지스틱 회귀 | 모형 유의(χ² = 193.4, p < .001) |

**시사점**: 경험 기반 직무탐색이 전공-직무 일치를 높이고, 이는 직업의 발전 가능성과 안정성을 긍정적으로 인식하게 만든다. 대학 교육과정에 현장 경험을 구조적으로 넣을 필요가 있다.
